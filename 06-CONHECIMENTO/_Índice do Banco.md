# 🗃️ Banco de Conhecimento

Memória criativa permanente. Tudo que é aprovado vira arquivo aqui (templates +
backlinks). O painel em [[Painel Central]] lê estes dados.

- **Barras/** — melhores linhas (tema, emoção, intensidade, qualidade)
- **Refrões/** — hooks aprovados (viral, comercial, nota)
- **Conceitos/** — ideias de faixa (originalidade, profundidade, single/álbum)
- **Metáforas/** — imagens-motor reutilizáveis
- **Simbolismos/** — extensões do [[Universo Simbólico]]
- **Referências/** — dossiês do Diretor de Pesquisa (A1)

> Os arquivos abaixo marcados `[SEED]` são exemplos que definem o PADRÃO de
> qualidade. Estude-os, depois apague quando tiver os seus.
