# Barra  `[SEED]`

> Juram lealdade no sol, mas traem na neblina;
> anoto cada nome no verso de uma folha de oliva.

**Técnica:** misdirection + símbolo subvertido (oliva = paz → mas ele a usa como
caderno de inimigos) + rima slant multissílaba (neblina/oliva).
**Camada que abre:** filosófica (paz como disfarce; vingança paciente).
**Por que funciona:** mostra em vez de contar; subverte uma imagem manjada (paz);
sem clichê de "haters" — o vilão é nomeado e arquivado, não xingado.
