# 🏢 Organograma do Estúdio

```
                         [A0] CEO Criativo
                  (visão • posicionamento • veto final)
                                 │
        ┌────────────────┬───────┴───────┬──────────────────┐
   [A1] Pesquisa   [A2] Conceito    Composição          [A9] Grammy Board
                                         │              (avaliação 0–100)
                          ┌──────────────┼───────────────┐
                     [A3] Hook    [A4] Versos      [A5] Punchlines
                          └──────────────┼───────────────┘
                                 [A6] Flow / Cadência
                                         │
                              [A7] Editor de Linguagem
                                         │
                            [A8] Especialista em Viralidade
```

## Como invocar
Carregue o arquivo do agente como persona antes de rodar a etapa, ou use o
slash command correspondente (ver `.claude/commands/`).

## Departamentos consolidados (sub-funções dentro dos agentes acima)
- **Pesquisa (A1)** acumula: histórico, filosófico, religioso, psicológico,
  simbologia, cultura pop, tendências, narrativas virais.
- **Composição** acumula: storytelling, rima, cadência, melodia.
- **Emoção** é uma lente aplicada por A4/A5 (dor, ambição, raiva, transcendência,
  fé, paranoia, mistério, poder) — ver `03-SOPS/SOP - Verso.md`.
