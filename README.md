# SIX ONE SIX MAFIA — Selo Criativo Autônomo de Composição

Vault Obsidian + sistema de agentes operado por Claude Code para compor trap/rap
de alto nível, com memória permanente e melhoria contínua.

## ⚡ Instalação (5 min)
### Obsidian
1. Baixe o Obsidian (obsidian.md).
2. **Abrir pasta como cofre** → selecione a pasta `616-MAFIA-STUDIO`.
3. Plugins da comunidade: **Dataview** (obrigatório — alimenta os dashboards) e
   **Templater** (opcional). Em Dataview, ative "Enable JavaScript Queries".
4. Abra `00-DASHBOARD/Painel Central.md`.

### Claude Code
1. Terminal na pasta `616-MAFIA-STUDIO` → rode `claude`. O `CLAUDE.md` vira o cérebro.
2. Comandos em `.claude/commands/` viram slash commands:
   `/pesquisar /conceito /estrutura /refrao /verso /punchline /revisar /avaliar /finalizar /aprender`.

## 🎬 Fluxo de uma música
```
/pesquisar tema: dívida de sangue
/conceito        /estrutura
/refrao          /verso 1
/punchline       /revisar
/avaliar         /finalizar        /aprender
```
