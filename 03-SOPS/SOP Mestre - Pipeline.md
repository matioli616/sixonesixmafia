# SOP Mestre — Pipeline de Produção

**Objetivo:** padronizar a produção de uma faixa do zero ao master de letra.
**Gatilho:** novo tema/briefing.

## Sequência (não pule etapas)
1. `/pesquisar` → dossiê (A1)
2. Brainstorm → 3 fios (A1/A2)
3. `/conceito` → conceito + 5 camadas (A2) + veto (A0)
4. `/estrutura` → arquitetura da faixa
5. `/refrao` → hook (A3)
6. `/verso` → versos (A4)
7. `/punchline` → afiar (A5)
8. `/revisar` → flow + linguagem (A6/A7)
9. Revisão artística → coerência de universo (A0)
10. `/avaliar` → nota 0–100 (A9)
11. `/finalizar` (só se ≥85) + `/aprender`

## Critério de avanço
Só avança de etapa quem passou nos 4 portões de qualidade do `CLAUDE.md §5`.

## Checklist de saída da faixa
- [ ] Conceito com 5 camadas distintas
- [ ] Hook testado nos 5 critérios
- [ ] ≥ 2 punchlines por verso aprovadas
- [ ] Flow marcado e dentro do pocket
- [ ] Zero clichê do Léxico Proibido
- [ ] Nota Grammy ≥ 85
- [ ] Barras/refrão extraídos pro banco
- [ ] Aprendizado registrado
